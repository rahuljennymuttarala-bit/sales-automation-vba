# Sales Automation & MIS Reporting – Excel VBA

An Excel VBA automation project designed to streamline recurring sales MIS reporting, data processing, KPI calculations, and management reporting.

## 📊 Project Overview

This project demonstrates how Excel VBA can be used to automate repetitive sales reporting activities and convert raw sales data into a structured management information system (MIS).

The solution focuses on improving reporting efficiency, reducing repetitive manual work, standardizing report preparation, and providing management-ready sales information.

## 🎯 Business Objective

Sales teams often spend significant time preparing recurring reports manually.

This project aims to automate key reporting activities such as:

- Sales data processing
- Data cleaning and preparation
- KPI calculations
- Sales summaries
- Management reporting
- Report formatting
- Recurring MIS report generation

The objective is to create a more efficient and repeatable reporting workflow using Excel VBA.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- **Excel VBA (Visual Basic for Applications)**
- **Pivot Tables**
- **Excel Formulas**
- **Charts & Visualizations**
- **MIS Reporting**
